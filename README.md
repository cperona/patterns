# Design Patterns:
Classification by type:
1. Creational patterns:
   Flexible and controlled object creation.
2. Structural patterns:
   Group classes and objects to form greater, more flexible and efficient structures.
3. Behavioral patterns:
   Communication and collaboration between objects and responsibility distribution.
